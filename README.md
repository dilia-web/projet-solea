# SOLÉA

Site statique de présentation et de vente de soins solaires.

## Aperçu local

Ouvrir `index.html` dans un navigateur.

## Publication

Le site est publié sur GitHub Pages avec GitHub Actions à chaque push sur la branche `main`. Dans le dépôt GitHub, vérifier dans **Settings > Pages** que la source de publication est réglée sur **GitHub Actions**.
